# 나이 추정 모델 후보 비교 (D35)

- 작성: AI / 상태: **PM 승인 대기** (2026-10-24)
- 결론 요약: **후보 B (ViT age-gender, fp32)를 권고.** 정확도가 확실히 높고 Mac WebGPU에서 충분히 빠르다. 대신 파일이 크고(345MB) WebGPU가 없으면 느리며, 학습 데이터가 비상업 라이선스다.

## 1. 후보

| | 후보 A: InsightFace genderage | 후보 B: ViT age-gender |
|---|---|---|
| 파일 | `buffalo_l/genderage.onnx` | `onnx/model.onnx` |
| 출처 | InsightFace buffalo_l 모델 팩 (HF 미러 `public-data/insightface`, 커밋 `33c1063`) | `onnx-community/age-gender-prediction-ONNX` (커밋 `6c138f6`), 원본 `abhilash88/age-gender-prediction` |
| 구조 | MobileNet 계열 소형 CNN | ViT-B/16 (Vision Transformer) |
| 크기 | **1.3MB** | **345MB** (int8 변환 시 87MB, 아래 참고) |
| 입력 | `data` [1,3,96,96] RGB 0~255 (정규화는 모델 안) | `pixel_values` [1,3,224,224] RGB, /255 후 ImageNet 평균·표준편차 |
| 출력 | `fc1` [1,3] = [여, 남, 나이/100] | `logits` [1,2] = [나이, 성별 확률] |
| 크롭 | 박스 긴 변 × 1.5 | 박스 긴 변 × 1.3 |
| **라이선스** | **비상업 연구용만** (InsightFace 사전학습 모델 공지: 학습 데이터와 그 데이터로 학습한 모델은 비상업 연구 목적에 한함) | 모델 카드는 **Apache-2.0**. 단 학습 데이터 **UTKFace가 비상업 연구용**이라 상용화 때 법적 검토 필요 |
| 전시 사용 | 가능 (비영리 전시) | 가능 |
| 상용화 때 | **교체 필요** | 검토 필요 (교체 가능성 있음) |

## 2. 정확도

### 평가 방법
- 브라우저 모듈과 **같은 파이프라인**으로 처리: MediaPipe `blaze_face_short_range` → 가장 큰 얼굴 → 정사각 크롭(밖은 검정) → 모델. 스크립트: [`eval/eval_age.py`](../eval/eval_age.py)
- 데이터 (평가에만 사용, 저장소에 넣지 않음):
  - **AgeDB** 804장 (정확한 나이, 30~80세, 45~65세를 많이 뽑음). 두 후보 모두 학습에 쓰지 않은 것으로 보여 **가장 공정한 비교**.
  - **FairFace validation** (CC BY 4.0) 중 40~49세, 60세 이상 구간 1,792장. 인종 라벨로 동아시아인 따로 집계.
  - **face-age-gender-asian test** 1,179장 (아시아인). 출처가 불분명해 UTKFace와 겹칠 수 있음 → 후보 B에 유리할 수 있다.
- 얼굴 검출 성공: 3,627 / 3,775장 (검출 실패 사진은 제외).

### AgeDB (공정 비교, 800장)

| 지표 | A InsightFace | B ViT |
|------|---------------|-------|
| 나이 오차 MAE | 10.3세 | **7.7세** |
| 50~60세 MAE | 10.5세 | **6.6세** |
| 50~60세 평균 편향 (+는 나이 많게) | +3.2세 | −0.6세 |
| **55 경계 정확도 (50~60세)** | 58.6% | 60.5% |
| 60세 이상 → senior | **84.6%** | 82.2% |
| 45세 이하 → non_senior | 77.6% | **89.7%** |

(두 후보 모두 크롭 배율 1.5에서 잰 값. 후보 B는 int8 변환본으로 쟀고, 전체 데이터에서 fp32와의 차이는 1.5%p 이내였다. 크롭 배율 1.0/1.2/1.5/1.8 비교에서 B는 1.2~1.5, A는 1.5~1.8이 가장 좋아 각각 1.3, 1.5로 정했다)

### 전체 (AgeDB + FairFace + 아시아인 셋, 3,627장)

| 지표 | A InsightFace | B ViT fp32 | B ViT int8 |
|------|---------------|------------|------------|
| 나이 오차 MAE (정확한 나이 1,785장) | 10.4세 | **4.9세** | 5.0세 |
| 55 판정 정확도 (정확한 나이) | 83.2% | **88.2%** | 88.1% |
| 55 경계 정확도 (50~60세, 293장) | 57.7% | **59.4%** | 60.4% |
| 40~49세 → non_senior (구간 1,382장) | 80.9% | **89.7%** | 89.9% |
| 60세 이상 → senior (구간 460장) | 58.5% | **79.8%** | 78.3% |
| 동아시아인 40~49세 → non_senior (246장) | 80.9% | **92.7%** | 93.1% |
| 동아시아인 60세 이상 → senior (97장) | 50.5% | **77.3%** | 76.3% |

### 해석
- **50~60세 경계 판정은 두 후보 모두 60% 안팎**으로 동전 던지기보다 조금 나은 수준이다. 사진 한 장의 나이 오차가 5~10세라 피할 수 없다. 이 구간은 연속 5프레임이 잘 안 맞아 **8초 타임아웃 → 일반 화면 + "쉬운 화면으로 보기" 버튼(D16)**으로 처리되는 것이 설계 의도와 맞다.
- 판정이 분명해야 할 구간(40대, 60대 이상)에서 **후보 B가 10~25%p 더 정확**하다. 특히 동아시아인 60세 이상을 senior로 맞히는 비율이 A 50% vs B 77%로 차이가 크다. 전시 관람객 대부분이 한국인이므로 이 지표가 가장 중요하다고 본다.
- 후보 A는 정확한 나이 데이터에서는 60세 이상 재현율이 높지만(AgeDB), 구간 데이터·동아시아인에서는 크게 떨어진다. 데이터에 따라 흔들림이 크다.

## 3. 속도 (Mac, 브라우저 실측)

Chromium 152 (Claude 앱 내장 브라우저), Apple Silicon Mac, 데모 페이지 속도 비교, 30회 중앙값. 나이 모델만 잰 값.

| 후보 | WebGPU | WASM (CPU 1스레드) | 로드 |
|------|--------|---------------------|------|
| A InsightFace | 2.2ms | 2.1ms | 0.02~0.5초 |
| B ViT fp32 | **53ms** | 1,228ms | 0.9~1.1초 |
| B ViT int8 | 1,202ms (WebGPU 가속 안 됨) | 1,178ms | 0.2~0.4초 |

전체 파이프라인(`createAgeGate`, WebGPU)을 사진 영상으로 돌린 결과: 두 후보 모두 6fps 유지, 얼굴이 보인 뒤 **0.67초 만에 확정** (74세 → senior, 30세 → non_senior).

- **int8은 쓰지 않는다.** 정확도는 fp32와 같지만 WebGPU가 int8 연산을 지원하지 않아 Mac에서 20배 느려진다.
- WASM 멀티스레드(COOP/COEP 헤더 필요)는 데모 서버 설정 문제로 **측정하지 못했다.**

## 4. gram(Windows, 외장 GPU 없음) 위험 (D22)
- 후보 B는 WebGPU가 없으면 프레임당 약 1.2초 → 5프레임 확정에 약 6초로 8초 타임아웃에 빠듯하다.
- gram의 Intel 내장 그래픽은 Windows Chrome에서 보통 WebGPU를 지원하므로 큰 문제는 아닐 것으로 보지만 **실기기 확인 전까지는 미확인**이다.
- 대책 (모두 코드 변경 없이 가능): ① gram에서 `stableFrames=3` ② 그래도 느리면 gram에서만 `npm run models:setup -w ai -- --age=insightface-genderage`로 후보 A로 교체. 파일 이름이 같고 입력 이름으로 자동 인식하므로 프론트 수정이 없다.
- 전시(11/5)는 Mac이므로 전시 일정에는 영향이 없다 (D31).
