## 2. 시작 화면 디자인 (여러 차례 반복)

### 2-1. 첫 수정
> 메인 첫화면 글자 크기 확대, header부분 5173 배치 그대로 사용, 양옆에 빈 여백 없애기

- 제목 76→88px, 카드 제목 48→56px 등 한 단계씩 키움.
- 헤더를 옛 화면처럼 로고 왼쪽·도구 오른쪽 한 줄로. 가로 넓은 창에서 바탕색을 화면색으로 바꾸고 헤더·푸터 띠를 창 끝까지 이어 양옆 빈 여백 제거.
- 헤드리스 크롬(`chrome-headless-shell`)으로 스크린샷을 찍어 확인하기 시작.

### 2-2. 우루루 섹션
> 우루루 라고 되있고 돌아가는거 그 섹션 꽉차게 다른 디자인으로 변경해보자 3가지 아이디어 말해줘 / 2번 보여주고 3번 보여주고 해

- 3안 제안: 원탁 전폭 / 홍등 간판 / 메뉴 사진 띠. 홍등 간판과 사진 슬라이드를 `?hero=` 스위치로 비교.
- 사진 화질 문제 발견: 기존 메뉴 사진 80장이 480×359(카드용 캡처본). 사용자 질문 "사진 화질이 너무 않좋은데 왜 그런거야?"에 원인 설명.
- 사진 모자이크(3×2) → 사용자 요청으로 **공식 출처 4가지 방식**(Toast 환영 화면 배경 / LG 대기모드 광고 / 접근성 기준 별표5 우선 / 메뉴 미리보기)을 `?hero=toast|lg|a11y|preview`로 구현해 비교.

### 2-3. 참고 사진 기반 재구성
> [사진 첨부] 이거 삭제해주고 자연스럽게 크기 맞춰봐 / 사진 아래쪽에도 이런디자인 자연스럽게 … 아래쪽 테두리 부분

- 변형 4개 삭제. 사진 위 + 크림색 곡선 판 아래 구조(A안). 둥근 배지는 사용자 요청으로 삭제.
- 곡선 판 윗선을 따라 도는 회문(回紋) 띠를 SVG로 계산해 그림(`CurveMeander`, 이후 B안 확정으로 삭제).

### 2-4. 사진 슬라이드
> 딤섬 사진 있는 부분 사진 화질 가장 좋은 걸로 5장 자연스럽게 넘어가는 모션 그래픽 넣어줘 / 양쪽 여백은 절대 있으면 안돼 / 사진부분 화면 누르면 사진이 멈추고 때면 다시 자연스럽게 넘어가는 걸로 / 중국집에서 메인은 음식들 위주로 우선 순위

- 5장, 6초 간격, 1.2초 교차 전환. 누르고 있는 동안 멈춤(포인터 이벤트), 떼면 재개. `prefers-reduced-motion`이면 정지.
- 전환 중 양옆 번쩍임 문제("사진 넘어갈때 양쪾 사이드 번쩍번쩍") → 전 사진을 밑에 남겨 두고 새 사진만 위에서 나타나게 해 해결.
- 흰 사진 위쪽이 어두워지는 문제 → 사진 윗부분 평균색을 캔버스로 계산해 막 색을 사진에 맞춰 물들임(A안 전용, 이후 삭제).

- **데이터는 안 건드린 불일치**(사용자 확인 대기): 가격 차이 다수(예: 유니짜장 8,000→9,000, 깻잎차돌 짬뽕 14,000→16,000, 안심 45,000→48,000), 메뉴판에만 있는 항목(소룡포 샘플러, 트러플 소룡포·하가우, 해물 백짬뽕, 버섯 소고기 덮밥, 디저트 4종, 코스), 우리에만 있는 항목(옥수수 게살스프, 공심채 볶음, 빙화 비취냉면).

> 메뉴판 부분 footer에 이전 화면 없애고 화면 설정 넣기, 거기 안에 글자 크게, 음성 안내 설정까지 넣어줘

- 메뉴판 아래 버튼: [처음으로][화면 설정][직원 호출 · 도움]. 화면 설정 팝업에는 글자 크게·음성 안내·고대비·낮은 화면 토글(이미 있던 팝업 재사용). 메뉴판 머리는 로고·카메라 표시만.

캡처: `05_메뉴판_분류재배치.png`, `06_메뉴판_푸터_화면설정.png`, `07_화면설정_팝업.png`

## 6. 반응 없음 안내창

> 화면 반응 없을때 다시 메인 화면으로 돌아가는 안내창 깔끔하게 바꿔주고 20초면 20,19,18,17 로 줄어들게해줘 / 다되면화면에 띄워줘

- 제목 "아직 계세요?" 가운데, 닫기 버튼 숨김. 금색 고리 안에 남은 초가 매초 줄고 고리도 함께 줄어듦(`role="timer"`). 버튼 [계속 주문하기][처음으로].
- 60초 무반응 → 안내 → 20초 뒤 처음으로 가는 기존 타이머는 그대로. 실제 60초를 기다려 캡처해 확인.

캡처: `08_반응없음_안내창.png`

## 7. 주문 → 결제 흐름

> 함께 드시면 좋아요 없애줘 바로 결제 페이지로 넘어가게 해줘 → 담은 메뉴 한번더 확인시켜주는걸로 변경하자

- 곁들임 제안(upsell) 팝업과 `pairings` 함수·테스트·스타일 삭제. 대신 **"담은 메뉴를 확인해 주세요"** 팝업: 줄마다 이름·수량·금액, 합계, [이대로 결제하기][더 담을게요].

> 결제 화면에서 결제하기 버튼을 어디에서 먹은지 안정하고 터치하면 매장에서 먹기 포장하기가로 눈이 갈수 있게 반짝반짝해줘 / 결제수단도 … 선택 안되있는 상태로 변경 / 결제 버튼 활성화 되기전까지는 눌리는 반응 없게 / 결제 수단도 선택안하면 … 똑같이 처리 / 간편결제는 3가지 페이 버튼중 사용자가 정하게 / 간편결제하고 결제하기 버튼 누르면 페이버튼들만 빤짝이게

- 먹는 곳·결제 수단·간편결제 종류 모두 처음엔 비어 있음(미리 선택 없음).
- [결제하기]는 다 고르기 전엔 흐리고 눌림 효과 없음(`aria-disabled`). 누르면 **안 고른 칸만** 2.6초 금색 반짝임 + 칸 제목 붉게 + 안내문("매장에서 드실지 포장하실지, 결제 수단을 먼저 골라 주세요." 등 빠진 것에 맞춰 조합) + 그 칸으로 스크롤. 간편결제 종류만 빠졌으면 페이 버튼 3개만 반짝임.

> 카드 결제 모달도 깔끔하게 변경해줘

- 제목 가운데, 닫기 숨김, 그림 작게, 금액 크게, 요약 3줄(먹는 곳·결제 수단·메뉴 수), 안내 한 줄, 버튼 2개 가로 가득. 반응 없음·담은 메뉴 확인 팝업과 같은 폭(760)·같은 틀로 통일.

캡처: `09_담은메뉴_확인.png`, `10_결제_선택유도.png`, `11_결제_페이선택유도.png`, `12_결제_확인팝업.png`
