# @menumate/ai v1 구현 계획

> **에이전트 작업자용:** 필수 하위 스킬: superpowers:executing-plans. 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 브라우저 안에서 55세 이상 여부를 판정하는 `createAgeGate`, 순수 판정 함수 `ageGateReducer`, 기기 내장 음성만 쓰는 `createSpeaker`를 `@menumate/ai` 패키지로 제공한다.

**구조:** MediaPipe 얼굴 검출 → 가장 큰 얼굴 크롭 → ONNX Runtime Web 나이 추정 → 순수 리듀서가 계약 이벤트로 바꾼다. 검출기·추정기는 주입식(`createAgeGateCore`)이라 브라우저 없이 테스트한다.

**기술:** TypeScript (빌드 없음, `src/index.ts` export), `@mediapipe/tasks-vision` 1.1.1, `onnxruntime-web` 1.30.0, vitest, Vite(데모), Python(평가 전용).

**명세:** [`docs/contracts/ai-output.md`](../../contracts/ai-output.md), [`ai/RULES.md`](../../../ai/RULES.md), [`docs/00_pm_decisions.md`](../../00_pm_decisions.md)

> 진행 메모 (2026-10-24): PM 지시가 오기 전에 Task 1~6을 먼저 구현해 커밋했다(538c0aa). 테스트는 구현과 함께 썼고 엄밀한 "실패 먼저" 순서는 아니었다. 아래 체크는 실제 상태다.

## 전역 제약
- 기준 나이 55 (D3), 연속 5프레임, 신뢰도 0.7, 타임아웃 8000ms (D16), 6fps — 모두 config로 덮어쓸 수 있다.
- 실행 중 인터넷·CDN 금지. 모델·WASM은 config의 로컬 URL에서만 (D32).
- 추정 나이 숫자, 프레임 이미지는 모듈 밖으로 나가지 않는다. 저장·로그 금지 (D2).
- WebGPU 실패 시 WASM으로 (D22). TTS는 `localService === true` 한국어 음성만 (D28).
- 수정 범위는 `ai/`와 이 계획 파일뿐. `ai/models/`, 루트 `package-lock.json`은 커밋 금지.

## 리뷰 포커스
1. 얼굴 검출이 한두 프레임 깜빡이면 `no_face`로 타이머가 초기화된다 → 경계 나이 손님이 8초를 넘겨도 timeout이 안 날 수 있다. 실측(Task 8)에서 확인하고 PM에 보고.
2. 추론이 계속 실패하면 `error`가 한 번만 오고 판정이 멈춘 채로 남는다 → 프론트가 `error`를 받으면 타임아웃과 같이 일반 화면으로 가야 한다 (계약 보충으로 PM에 질문).
3. 확정 뒤 `force()`가 다시 `decided`를 보낸다 → 프론트 리듀서가 두 번째 decided를 처리하는지 (테스트: `force는 확정 뒤에도 동작한다`).
4. 탭이 숨겨지면 타이머·영상이 멈춘다 → 키오스크는 전체 화면이라 영향 없음. 데모에서만 주의.
5. WebGPU 첫 실행 지연(수 초) → 로드 때 검출기·추정기 준비 실행으로 흡수 (브라우저 실측 확인).
