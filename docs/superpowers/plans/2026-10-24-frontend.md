# Frontend v1 (키오스크 웹 앱) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 10/27 최종 점검(D29) 범위의 키오스크 흐름(인식 → 질문 4개 → 추천 3개 → 매장/포장 → 장바구니 → 결제 시뮬레이션 → 주문번호)을 가짜 AI·API로 끝까지 동작시키고, 통합 때 진짜 모듈로 바로 바꿔 끼울 수 있게 만든다.

**Architecture:** 화면 상태는 `kiosk-flow.md` 전이표를 옮긴 순수 리듀서(`src/kiosk/reducer.ts`) 하나가 가진다. API·카메라·TTS·타이머·단축키 같은 부수 효과는 `useKiosk` 훅 한 곳에 모으고, 화면 컴포넌트는 상태를 그리고 명령을 부르기만 한다. 가짜 AI(`src/mocks/ai.ts`)와 가짜 Backend(`src/mocks/mockBackend.ts`, Vite 개발 서버 미들웨어)는 `.env`의 `VITE_MOCK_AI`, `VITE_MOCK_API`로 켜고 끈다.

**상태 (10/24):** Task 1~7 완료. 테스트 61개 통과, 빌드 성공, 브라우저로 두 흐름 확인 (`frontend/docs/screenshots/`).

**Tech Stack:** React 19 + TypeScript 5.9 + Vite 8, Vitest 5 + Testing Library + jsdom, 로컬 폰트(Pretendard, Black Han Sans, npm 패키지로 번들)

**Spec:** `docs/00_pm_decisions.md`, `frontend/RULES.md`, `docs/contracts/kiosk-flow.md`, `api.md`, `ai-output.md`, `questions.md`, `menu-schema.md`, `docs/env-guide.md`, `frontend/docs/PRD.md`

## Global Constraints
- 기준 캔버스 세로 1080×1920, 넓은 창에서는 가운데 (D25)
- 쉬운 화면: 본문 28px 이상, 버튼 높이 72px 이상, 대비 7:1 이상, 한 화면 선택지 4개 이하
- 판정 후 모든 화면 상단에 "쉬운 화면으로 보기" / "일반 화면으로 보기"
- 무입력 60초(`VITE_IDLE_RESET_MS`), 주문번호 화면 10초(`VITE_DONE_RESET_MS`) 뒤 초기화. 연령·취향·장바구니 삭제 (D30)
- 시연 단축키 Shift+S/N/F/R은 `VITE_DEV_SHORTCUTS=true`일 때만, 화면 표시 없음
- 얼굴 이미지·나이 숫자를 상태·저장소·로그·화면에 두지 않음. 연령대는 API로 보내지 않음 (D2, D47)
- CDN 금지: 폰트·아이콘·이미지는 프로젝트에 포함 (D32)
- 메뉴명·가격·질문 문구를 운영 코드에 박지 않음 (가짜 Backend만 예외, 통합 후 끔)
- 결제는 `PaymentPort.pay()` 뒤에 둔다 (D13)
- `frontend/` 밖은 고치지 않는다 (이 계획 파일 예외). 루트 `package-lock.json` 커밋 금지

## Review Focus
- 결제·추천 응답이 초기화(60초, Shift+R) 뒤에 늦게 도착 → 새 손님 화면이 바뀌면 안 됨 (세션 토큰으로 버림, 리듀서도 화면 검사)
- 질문 목록을 못 받은 상태에서 55+ 판정 → 질문 화면이 멈추지 않고 오류 + "그냥 메뉴 볼래요"로 빠져나감
- 카메라 권한 거부·모델 로드 실패 → 화면 오류 없이 터치·단축키로 진행 (D46)
- 서버가 꺼져 있음 → 대기 화면 "잠시 후 이용해 주세요", 5초마다 재확인, 터치 시작 막음
- 메뉴 사진 URL이 깨짐 → 카테고리 색 카드로 대체 (D40)
