## 1. 과제 목적

식당·카페 등 지역 상권에 무인 키오스크가 빠르게 늘고 있지만, 작은 글씨와 많은 메뉴, 여러 단계의 화면 때문에 고령층은 혼자 주문하기 어렵습니다. 고령 손님이 주문을 포기하거나 직원의 도움을 기다리는 일은 지역 소상공인에게도 매출과 인력 부담으로 이어집니다.

본 과제는 **카메라로 손님의 연령대를 추정해 55세 이상이면 화면이 자동으로 큰 글씨·음성 안내 모드로 바뀌고, 짧은 질문만으로 메뉴를 추천하는 키오스크**를 개발하여, 고령층이 도움 없이 스스로 주문을 끝낼 수 있게 하는 것을 목적으로 합니다. 협력 식당(우루루 본점)의 메뉴를 대상으로 하며, 얼굴 영상과 나이는 저장하지 않는 개인정보 보호 설계를 함께 목표로 합니다.

## 2. 과제 내용

**① 연령 인식과 자동 화면 전환 (AI·컴퓨터 비전)**
- 브라우저 안에서 동작하는 On-device AI(MediaPipe 얼굴 검출 + ONNX 나이 추정 모델)로 연령대를 35세 미만 / 35~54세 / 55세 이상으로 판정합니다.
- 두 후보 모델을 사진 3,627장으로 비교해 선정했고, 웹캠 실측에서 정면 기준 약 0.7초 만에 판정했습니다.
- 영상은 기기 밖으로 나가지 않으며 얼굴·나이 숫자는 저장하지 않습니다. 연령대도 서버로 보내지 않습니다.

**② 고령층 친화 화면 (UI/UX)**
- 21인치 세로 모니터 기준, 큰 글씨 모드는 글자 28px·버튼 72px 이상, 대비 7:1 이상, 한 화면에 한 가지 일만 하도록 설계했습니다.
- 질문을 음성으로 읽어 주고, 지금 눌러야 할 버튼의 테두리가 은은하게 빛나 다음 단계를 안내합니다.
- 담긴 메뉴를 다시 눌러 수량이 늘어나는 문제 등 사용성 문제 13가지를 미리 찾아 개선했습니다.

**③ 리뷰 학습 기반 추천 엔진 (데이터 분석)**
- 공개 식당 리뷰 64만 건과 배달앱 리뷰 12.9만 건에서 메뉴별 특징(맵기·부드러움·국물·든든함·담백함)과 평판을 학습했습니다.
- 체험단·협찬 등 광고성 리뷰는 규칙 기반 필터로 제외했습니다.
- 질병관리청 국민건강영양조사(2024, 6,805명)로 연령대별 실제 섭취 경향을 반영해, 같은 취향이라도 연령대에 맞게 추천 순서가 달라집니다.
- 추천마다 "또래 분들이 자주 드세요", "손님 평이 좋아요" 같은 근거를 함께 보여 줍니다.

**④ 주문·결제 시스템 (웹·백엔드)**
- 질문 5개 → 추천 3개 → 매장/포장 → 주문 확인 → 결제(시뮬레이션) → 주문번호까지 한 흐름으로 동작합니다.
- React·TypeScript 화면과 Node.js(Fastify)·SQLite 서버로 구현했고, 인터넷 없이 노트북 한 대로 운영됩니다.

**⑤ 개발 과정과 검증**
- 기획 → 계약 문서 합의 → 역할별 동시 개발 → 통합의 순서로 진행했고, 결정 85건을 문서로 남겼습니다.
- 자동 테스트 338개가 모두 통과했습니다.
- 새 디자인을 적용했다가 실제 화면을 보고 "이전보다 쓰기 어렵다"고 판단해 되돌리는 등, 보기 좋은 화면보다 쓰기 쉬운 화면을 기준으로 결정했습니다.
- 고령층 사용성 테스트(55세 이상 2명)는 [11/1~11/3 진행 예정]입니다.

## 4. 활용방안 및 기대효과

**활용방안**
- **협력 식당 실증**: 우루루 본점의 실제 메뉴 데이터를 넣어 매장에 시범 설치할 수 있습니다. 메뉴 파일만 바꾸면 되도록 설계했습니다.
- **업종 확대**: 카페, 분식점, 병원·관공서 접수 키오스크 등 화면 선택이 많은 무인 서비스에 그대로 적용할 수 있습니다.
- **저비용 보급**: 일반 노트북·모니터·웹캠으로 동작하고 인터넷이 필요 없어, 소규모 상점도 부담 없이 도입할 수 있습니다.
- **확산**: 설계 문서·결정 기록·코드를 정리해 다른 대학의 캡스톤·SW 교육 자료나 지역 디지털 포용 사업에 공유할 수 있습니다.

**기대효과**
- **고령층**: 직원 도움 없이 스스로 주문하는 경험을 늘려 디지털 소외를 줄입니다.
- **소상공인**: 주문 응대 부담이 줄고, 고령 손님의 주문 포기를 막아 매출에 도움이 됩니다.
- **교육 성과**: 스마트소프트웨어학과에서 배운 웹 개발, 백엔드·DB, 인공지능, 데이터 분석, 소프트웨어 공학을 하나의 실제 문제 해결에 통합했습니다.
- **지속 발전**: 실증 중 동의를 받은 익명 데이터로 연령대 추천을 계속 개선할 수 있습니다. 상용화 시에는 비상업 라이선스 학습 데이터 교체와 개인정보 법률 검토를 거칠 계획입니다.

**AI 활용 내역** (공모전 유의사항에 따른 기재)
- **도구**: Claude (Anthropic, Claude Code)
- **활용 단계·범위**: 기획 정리, 역할별 설계 문서 작성, 코드 작성 보조, 데이터 처리 보조, 문서 요약·문안 작성
- **팀의 수정·검증**: 모든 결정은 팀이 검토·승인했습니다. 코드는 자동 테스트 338개와 실제 실행으로 검증했고, 데이터 수치는 원자료로 확인했습니다.
- **원본 보관**: AI 대화 기록과 원자료를 보관합니다.
- **이미지**: 이 문서의 이미지는 모두 실제 개발 화면이며, AI 생성 이미지는 사용하지 않았습니다.
