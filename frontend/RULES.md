# Frontend 규칙

기준 문서: [`docs/00_pm_decisions.md`](../docs/00_pm_decisions.md). 이 문서와 충돌하면 PM 결정이 우선한다. 괄호 안 번호(D00)는 그 문서의 결정 번호다.

> 2026-10-29 D86: 화면은 팀원 저장소 menumate_DL의 키오스크 UI를 기반으로 한다. 이전 구조(kiosk-flow 질문 5개 흐름, 디자이너 시안 기반)는 git 히스토리에 있다. 아래는 지금 구조 기준이다.

## 1. 담당 산출물
1. **키오스크 웹 앱** (`frontend/src/prototype/`)
2. 우루루 메뉴·사진·리뷰 데이터 반영 (`frontend/src/prototype/menu/`, D87)
3. 공동 작업: 환경 변수 관리 가이드, 시스템 아키텍처 구상도의 프론트 부분
4. 이전 `docs/contracts/kiosk-flow`, `questions`는 이 UI의 흐름과 맞지 않는다. 다시 쓰기 전까지 참고용이다.

## 1-1. 디자인 (D55 대체, D86)
- 방향은 **중식당 "원탁"**: 주칠·흑칠·금박·상아. 색과 장식은 `src/prototype/styles/theme.css` 한 곳에서 정하고, 그쪽 CSS는 건드리지 않고 마지막에 덮는다 (`KioskApp.tsx`에서 `theme.css`를 `overrides.css` 다음에 불러온다).
- 서체: 제목 Black Han Sans, 본문 Noto Sans KR. 둘 다 npm 패키지로 빌드에 포함한다 (D32).
- 새 색을 쓸 때 글자 대비 7:1 이상을 지킨다. 금박(`--gold`)은 장식과 선택 표시에만 쓰고 글자 색으로 쓰지 않는다.
- 디자이너는 현재 없다. Frontend가 디자인까지 맡는다 (D79).

## 2. 기술 스택 (D34)
- React 19 + TypeScript + Vite. 테스트는 Vitest.
- 실행: Chrome 키오스크 모드(전체 화면). 기준 해상도 **세로 1080×1920** (D25).
- 메뉴는 `src/prototype/menu/menus.json`을 직접 읽는다 (Backend API를 쓰지 않는다). 사진은 `menu/image/{메뉴 id}.webp`, 리뷰는 `menu/review/`.
- AI 모듈 `@menumate/ai`는 브라우저에서 import해서 호출한다. 직접 모델을 다루지 않는다. 모델 파일은 Backend가 `/models`로 제공한다 (vite 개발 서버가 4000 포트로 프록시).

## 3. 화면과 흐름
시작 → (메뉴 보고 주문 | 말로 추천 받아 주문) → 메뉴판/추천 결과 → 결제(매장/포장, 카드·간편결제 시뮬레이션) → 주문번호·영수증(QR) → 시작. 무입력 60초 후 확인 팝업, 20초 뒤 처음으로. 자세한 기능은 [`menumate_DL` README] 기준이다.

## 4. 연령대 판정: 반드시 우리 AI (D86, D88)
- 나이 추정은 **`@menumate/ai`(MediaPipe 얼굴 검출 + ONNX 나이 추정)만** 쓴다. face-api 등 다른 비전 모델을 들이지 않는다.
- 판정 훅은 `src/prototype/ageAssist.ts`. 55세 이상(`55plus`)이면 큰 글씨와 음성 안내를 켜고, 손님이 직접 바꾼 설정은 덮어쓰지 않는다.
- 우리 AI는 55세 미만·35~54세·55세 이상 3단계만 낸다. 어린이 판정은 없으므로 '낮은 화면'은 손님이 직접 켠다.
- 큰 글씨 화면에서는 눌러야 할 주 버튼에 금박 빛 테두리를 둔다 (D78). 한 주기 1.2초, "동작 줄이기" 설정이면 멈춘다.
- "55세 이상 강제 인식"은 **키보드 단축키(Shift+S / Shift+N)로만** 둔다 (`VITE_DEV_SHORTCUTS`). 화면에 개발용 버튼을 노출하지 않는다 (D24).

## 5. 전시와 시연 (D24, D30, D32)
- 정상 흐름을 화면 녹화한 백업 영상을 11/5 전까지 만든다.
- 인터넷 없이 동작해야 한다 (D32). 웹폰트, 아이콘, 이미지를 CDN에서 불러오지 않는다.
- 예외(인터넷 필요): 브라우저 음성 인식(말로 추천·주문), 휴대폰 영수증 QR(`menumate-dl.vercel.app`). 끊기면 메뉴판에서 직접 고르기로 안내한다.
- 전시 빌드(`npm run build`)에서는 가짜 AI(`VITE_MOCK_AI=true`)가 막힌다.

## 6. 데이터와 개인정보 (D2)
- 얼굴 이미지는 저장하지 않는다. `localStorage`, `IndexedDB`, 서버 업로드, 콘솔 로그 모두 금지.
- 카메라 프레임은 AI 모듈에 넘기고, 받은 연령대 결과만 상태에 보관한다. 원본 나이 숫자는 화면에 표시하지 않는다.
- 사용 통계(`#/stats`)는 이 기기 브라우저에만 저장하는 익명 기록이다.

## 7. 인터페이스 규칙
- 메뉴명, 가격, 사진을 코드에 박지 않는다. `menus.json`과 `menu/image/`만 고친다 (사진 파일 이름 = 메뉴 id).
- 환경 변수는 `.env`에서만 읽는다. `.env`는 커밋하지 않고 `.env.example`만 커밋한다.
- Backend 시드·AI 엔진 메뉴 데이터는 아직 한식 더미다. 우루루 80개 메뉴로 맞추는 일은 후속 작업이다 (D87).
