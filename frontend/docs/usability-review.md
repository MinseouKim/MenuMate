# 사전 사용성 점검 (v2)

- 작성: Frontend / 2026-10-27 / 관련 결정: D70(예전 디자인 유지), D78(55+ 빛 테두리), D79(Frontend가 디자인까지)
- 기준 화면: 디자이너 합류 전 디자인(D55) + kiosk-flow v1.2 동작
- 참고: 디자이너 UI 감사 `design/audit.md`(디자인 브랜치, 읽기만). 그 가운데 아직 남은 문제와, 실제 손님(특히 55+)이 혼자 주문할 때 막힐 곳을 다시 골랐다.
- 원칙: **예전 모습(쪽빛 버튼, 검은 상단 띠, 간판 글씨) 안에서** 고친다. 색·서체·배치 방향은 바꾸지 않는다.

심각도: **치명** 혼자 주문을 끝내지 못할 수 있음 / **높음** 헤매거나 실수함 / **보통** 다듬을 것

## 1. 고칠 목록

| # | 심각도 | 화면 | 문제 (손님에게 일어나는 일) | 해결 (예전 스타일 안에서) | 상태 |
|---|-------|------|---------------------------|-------------------------|------|
| U1 | 치명 | 추천, 메뉴판 | 카드를 누르면 바로 담기는데 표시가 구석의 작은 배지뿐이라, 담겼는지 확인하려고 다시 누르면 2개·3개가 된다 | 카드 아래에 **"담기" 띠**를 둬서 누르는 곳을 보이게 한다. 담으면 띠가 노란 바탕 "✓ 담았어요"로 바뀐다. **큰 글씨 화면은 다시 눌러도 늘지 않고** 음성으로 "이미 담았어요. 개수는 주문 확인에서 바꿀 수 있어요."만 알린다. 기본 화면은 누를 때마다 1개씩 늘고 띠에 "N개 담음 +"가 보인다 | 완료 |
| U2 | 높음 | 질문, 매장/포장 | "네"와 "매장에서 먹기"만 쪽빛이라 정답·기본값처럼 보인다 | 두 버튼을 **같은 흰 버튼**으로. 네/아니요는 ○ / ✕ 기호, 매장/포장은 그릇 / 봉투 그림으로 구분한다 | 완료 |
| U3 | 높음 | 추천·메뉴판 하단, 메뉴판 앞/다음 | 비활성 버튼이 옅은 하늘색(불투명도 35%)이라 눌러도 될 것처럼 보이고, 왜 못 누르는지 말해 주지 않는다 | 비활성은 **회색 바탕 + 점선 테두리 + 흐린 글자**(불투명도 쓰지 않음). 주문하기 옆에 이유 "아직 담은 메뉴가 없어요" | 완료 |
| U4 | 치명 | 장바구니 | 수량 1에서 "−"를 누르면 확인 없이 메뉴가 빠진다 | 수량 1이면 "−" 대신 **"빼기"** 글자 버튼. 누르면 그 줄에서 "이 메뉴를 뺄까요? [빼기] [그대로 두기]"로 한 번 묻는다 (화면 안 상태, 리듀서 계약 그대로) | 완료 |
| U5 | 치명 | 메뉴판 (큰 글씨) | 한 화면에 누를 곳 14개, 할 일 5가지(AI·종류·메뉴·쪽·주문). "한 화면에 한 가지 일"이 아니다 | 큰 글씨 메뉴판을 **두 단계**로: ① "어떤 메뉴를 보시겠어요?" 종류만 크게 고르기 → ② 그 종류의 메뉴 4개씩 + "다른 종류 보기". 기본 화면은 지금 그대로(탭 + 3열) | 완료 |
| U6 | 높음 | 메뉴판 | "AI와 대화하기"와 "주문하기"가 같은 쪽빛이라 무엇이 다음 단계인지 흐리다 | 쪽빛(주 버튼)은 화면마다 **앞으로 가는 버튼 하나**만. "AI와 대화하기"는 흰 버튼, 주문번호 화면 "처음으로"도 흰 버튼 | 완료 |
| U7 | 높음 | 질문 | 첫 질문에서 음성은 인사를 읽는데 화면에는 질문만 있다. 지금 읽는 중인지도 안 보인다 | 1번 질문 위에 인사 한 줄을 화면에도 보인다(음성 = 화면). 읽는 동안 "다시 듣기"가 노란 "읽어 드리는 중…"으로 바뀐다 | 완료 |
| U8 | 높음 | 담기·빼기 | 큰 글씨 손님에게 담은 결과를 말로 알려 주지 않는다 | 큰 글씨 화면에서 "○○, 담았어요." / "○○, 뺐어요." / 빼기 확인을 음성으로 | 완료 |
| U9 | 높음 | 대기 | 카메라 안내가 24px 흐린 회색이라 고령층이 못 읽는다 (D20 상시 표시) | 28px 이상, 본문 먹색 | 완료 |
| U10 | 보통 | 주문번호 | 남은 초 문장이 흐린 회색 | 먹색 | 완료 |
| U11 | 보통 | 공통 | 터치 화면에서 두 번 탭 확대·터치 지연 | `touch-action: manipulation` | 완료 |
| U12 | 보통 | 메뉴판, 추천 | 실데이터의 긴 메뉴 이름이 카드를 넘친다 | 이름 한 줄, 넘치면 말줄임 | 완료 |
| U13 | 높음 | 큰 글씨 화면 전반 | 다음에 무엇을 눌러야 하는지 한눈에 안 보인다 | **빛 테두리**(D78): 지금 눌러야 할 버튼 1~2개의 테두리가 은은하게 빛난다. 1.2초 주기(초당 3회 미만), 동작 줄이기 설정이면 움직임 없이 테두리만 | 완료 |

## 2. 그대로 두는 것 (이유)
| 항목 | 이유 |
|------|------|
| 가격 고추색 | 예전 디자인 결정(D55, D70). 대비 7.7:1로 읽기에는 문제 없다 |
| 검은 상단 띠, 쪽빛 판 | 예전 디자인 유지(D70) |
| 인식 중 화면의 원 움직임 | 평균 0.67초만 보였다 사라지는 화면이고, `prefers-reduced-motion`에서 멈춘다. 빛 테두리와 같은 원칙(느리고 부드럽게) |
| 사진 없는 메뉴의 색 카드 + 메뉴명 | 예시 사진(D77)이 들어오면 대부분 사진으로 바뀐다. 사진이 없거나 깨지면 지금 색 카드 |
